## Site Features

* **Uncropped High-Resolution Previews:** Full-frame inspection modal for every Windows 11 visual style.
* **Community Discussions:** Powered by [Giscus](https://giscus.app) and GitHub Discussions—sign in with GitHub on any theme card to leave feedback or share desktop setups.
* **Live View Metrics:** Tracks per-release and portfolio-wide views automatically.
